# Changelog

See the project's [release history](https://github.com/Oneyann/stalzone-api/releases)
for published releases.

## 0.1.0 — initial release

- Synchronous and asynchronous Stalzone API clients.
- `AppClient` and `SyncAppClient` convenience facades with environment
  credential lookup and public demo server fallback.
- OAuth helpers, typed response models, pagination, retries, rate limiting,
  and API error mapping.
- Read-only access to the official Stalcraft item database from GitHub, local
  checkouts, or downloaded snapshots, with item search and icon access.
- Python 3.10+ support and PEP 561 typing marker.
